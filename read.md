Project: Google Maps Route Tracking

Instructions to run:
- Open index.html in a web browser (double-click or use a local server).
- Allow location access when prompted.
- Select a destination from the dropdown or click on the map to set a destination.
- Click "Get Route" to display driving directions from your current location.

Important: Replace the Maps API key in the script tag in index.html with your own API key from Google Cloud Console.
